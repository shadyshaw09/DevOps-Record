# Day 21

## Experiment Title

Introduction to Docker Compose and YAML Configuration

## Objective

To understand Docker Compose and learn how to configure containerized applications using a YAML configuration file.

## Theory

Docker Compose is a tool used to manage multi container Docker applications. It allows users to define services, networks and volumes inside a single YAML configuration file called docker-compose.yml. Multiple containers can be started and managed together using a single command.

Docker Compose simplifies application deployment and helps in managing container communication and configuration efficiently.

## Requirements

Docker Desktop

Docker Compose

Windows Operating System

## Procedure

Open Docker Desktop and verify that Docker Compose is installed successfully.

Create a new project directory for the Docker Compose application.

Create a docker-compose.yml file and define the required service configuration.

Run the Docker Compose application using Docker commands.

Verify that the container is running successfully.

Stop and remove the running containers after completion.

## Output

Docker Compose was successfully verified on the system.

A simple NGINX container was created and executed successfully using Docker Compose.

The application was accessible through port 8080.

## Result

Successfully learned the basics of Docker Compose and YAML configuration for managing containerized applications.
